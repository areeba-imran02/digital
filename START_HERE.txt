VERITAS — COMPLETE SOURCE CODE

1) Backend:
   cd backend
   python -m venv .venv
   Windows: .venv\Scripts\activate
   macOS/Linux: source .venv/bin/activate
   pip install -r requirements.txt
   uvicorn app.main:app --reload --port 8000

2) Frontend (new terminal):
   cd frontend
   npm install
   npm run dev

3) Open:
   http://localhost:5173

4) API docs:
   http://localhost:8000/docs

Docker:
   docker compose up --build

The project works without an AI API key. The AI provider layer is modular and can be connected later.
